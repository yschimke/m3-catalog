Each row pairs a glimmer-samples component with its declared glimmer-catalog parallel (the parallel field in the catalog spec). Both renders are static thumbnails — the left from this branch, the right baked from the design-artifacts/glimmer-catalog branch — and each links to the live preview server on click, where the component re-renders under other themes / locales / devices. A parallel that isn't catalogued in glimmer-catalog yet is flagged unpaired. Components with no parallel on either side are listed below the table.
